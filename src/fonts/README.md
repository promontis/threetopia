# Geist fonts

Official Vercel Geist Sans and Geist Mono variable WOFF2 files, including italics.
Vendored unchanged from the `geist@1.7.2` npm release so the Vite apps and static docs can self-host the full fonts without a Next.js dependency.

- Typeface: https://vercel.com/font
- Source: https://github.com/vercel/geist-font
- Release: https://registry.npmjs.org/geist/-/geist-1.7.2.tgz
- License: SIL Open Font License 1.1; see OFL.txt.

Shared font faces and family tokens are defined in `../typography.css`.
