02 · The technology

One renderer. One coordinate system. One graph of packages.

A marketplace is only as good as what runs underneath it. Threetopia is one Three.js scene streamed from regions that many people published, and a package graph that says exactly whose code is running where.

Renderer

Three.js WebGPU, TSL materials

The connected world uses WebGPURenderer and node materials written in TSL. The map has a separate renderer with simplified scene assets, bounded zoom and adjustable render quality.

import { WebGPURenderer }
  from 'three/webgpu'

Regions

128 m blocks with an edge contract

A region is 128 m square. The interior is free. Along each edge an 8 m band follows a shared profile: height samples, surface class, and connectors for rivers (level, width) and paths (width, slope). The world is a grid of these, so any region can be moved or turned by a quarter and still be checkable.

edges: {
  N: river({ level: 0, width: 6 }),
  E: path({ width: 3 }),
  S: none, W: none }

Seam solver

Wang-tile seams, checked before placement

Move or turn a region and the solver compares each edge with its neighbour: terrain blends inside the band, water must meet at the same level, paths within the slope limit, a river against a path needs an adapter. It reports every seam before mutating anything and rebuilds only the seams that changed.

N  river ↔ river  ✓ level 0.00 · 6 m
E  river ↔ path   ✕ no adapter

Packages

Ordinary npm, immutable versions

A component is a normal npm package: code plus static assets (textures, models, audio), at most 100 MB packed, on a private registry with a standard package.json and lockfile. A published version never changes. Components run as reviewed runtime code and validated recipe data, never as arbitrary uploaded scripts.

"name": "@threetopia/alex-ocean",
"version": "1.4.0",
"threetopia": { "kind": "water",
  "recipe": "./recipe.json" }

Provenance

Verified from the build, not from package.json

At publish time the built output is analysed. Only dependencies that are actually imported become verified edges; a package that is listed but never imported earns nothing. The tarball is content-hashed and the hash is part of the version. That graph, not a list you typed, is what settlement uses.

verified  tom-waves ✓  sarah-noise ✓
ignored   mia-sparkles ✕ never imported
hash      sha256:9f3c…a1e2

Settlement

Deterministic, cent-exact, auditable

Once a month, €8 of every subscriber is split evenly over the roots they chose, then inside each root by 1 / 2depth per payout account. Every line traces back to one root envelope; envelopes reconcile to the cent. The same code that will run settlement runs the calculator further down this page, with unit tests.

alex-ocean  €4.00
  Alex €1.78 · Sarah €0.89
  Tom  €0.89 · Bob   €0.44

Running today: the WebGPU renderer and the nine-region world it rendered, the seam checks between those regions, and the settlement policy behind the calculator (unit-tested). Prototype: the registry, the CLI, region streaming and payments.
