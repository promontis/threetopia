The CLI would check the tile format and every neighbouring edge. The preview is where you test the actual crossing. This is the workflow we’re building.

  ✓ Published forest@0.1.0.
  1. threetopia initSet up a tile with the shared coordinates, lifecycle hooks and asset manifest.
  2. threetopia add <component>Use a shared edge profile or build with something another creator has made.
  3. threetopia checkCheck size, scale, edge declarations and asset references. For a placement, compare all six sides with their neighbours.
  4. threetopia previewLoad the tiles together. Walk across borders and inspect collisions, materials, lighting and frame cost.
  5. threetopia publishPublish a version of your tile or component, with its dependencies and creator credits, ready for placement.

A preview of the intended workflow. The CLI is still in development.
