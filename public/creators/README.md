# Creator media sources

These assets identify the real creators and show their original work in the hero's
project dialogs. Little Birds and Lagoon Tree Village also illustrate the two
ways to contribute, with links to the original projects. These examples are
inspiration, not claims that the projects have joined Threetopia. The shared-world background is generated concept art inspired by
those projects; it is not a screenshot of their code running together.

The package explorer concept also uses these credited previews as example
listings. Package X-ray draws an original SVG maquette with illustrative package
combinations; it does not claim these projects depend on each other.

Preview images are browser screenshots of the original live demos or frames from
the original public X videos, selected after viewing the footage rather than using
automatic video posters. Images are only resized and WebP-compressed. The birds
preview is framed more closely with CSS; its source file contains the full video frame.
